Manufacturing Quality Control Analysis

Project overview

This project analyses 100 fictional production batches for two fictional paint product categories: Matt and Satin. The goal is to assess quality outcomes, identify common rejection drivers, and develop evidence-based operational recommendations.
Important data note
All records and specification limits are synthetic training data. They are not PCMN records, PCMN product specifications, or approved industry limits. They must not be represented as actual company data.
Files
- manufacturing_qc_analysis_starter.xlsx — workbook containing the project guide, batch data, fictional training specifications, and data dictionary.
- manufacturing_qc_batch_data.csv — raw input data for analysis.
Business questions
1. What is the overall batch acceptance and rejection rate?
2. Does quality performance differ between Matt and Satin?
3. Which defects account for the most rejected batches?
4. Are there any notable patterns by production month or batch size?
5. What practical actions could help reduce rejected batches?
Tools
Microsoft Excel: data inspection, cleaning, formulas, PivotTables, charts, and reporting.
Method
The workbook calculates SG checks, viscosity checks, overall QC status, defect category, and rework flag using formulas and fictional training limits shown on the Specifications sheet.
